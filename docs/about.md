# 🧠 Обо мне

## Моя история
Я учусь на 2 курсе Колледжа цифровых технологий «ТОП» в г.Обнинск. С самого начала обучения заинтересовался backend-разработкой, потому что мне нравится создавать логику, которая работает "под капотом" приложений.

## Что сейчас изучаю
1. **FastAPI** — для создания быстрых и современных API
2. **Docker** — чтобы упаковывать приложения в контейнеры
3. **Базы данных** — PostgreSQL для хранения данных и Redis для кэширования
4. **Асинхронное программирование** — для эффективной работы с I/O

## Цели на 2026 год
- Успешно закончить 2 курс 
- Создать свой первый полноценный backend-проект
- Разобраться с микросервисной архитектурой
- Научиться настраивать CI/CD для своих проектов

## Почему этот блог?
Здесь я буду делиться своими мыслями, писать DOCS для моих пет-проектов.
